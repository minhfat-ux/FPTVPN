# EVIDENCE RULES (RULE-EVID-*)

Baseline RULESET-0001. Source: master spec §57.

- RULE-EVID-001: No evidence = not verified.
- RULE-EVID-002: Evidence maps to requirement/task/test.
- RULE-EVID-003: Evidence must be reviewable/reproducible.
- RULE-EVID-004: Agent narrative alone is not evidence.
- RULE-EVID-005: Secret-bearing evidence must be sanitized.
- RULE-EVID-006: Contrary evidence invalidates stale verification.
