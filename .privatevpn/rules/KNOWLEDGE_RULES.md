# KNOWLEDGE RULES (RULE-KB-*)

Baseline RULESET-0001. Source: master spec §50.

- RULE-KB-001: Retrieve relevant KB items before implementation.
- RULE-KB-002: Do not send the entire KB to an agent.
- RULE-KB-003: Superseded knowledge must not be presented as active.
- RULE-KB-004: Knowledge items require provenance.
- RULE-KB-005: Agent opinion is not automatically authoritative knowledge.
- RULE-KB-006: Resolved bugs should create reusable knowledge where appropriate.
