# GLOBAL AGENT RULES (RULE-GLOBAL-*)

Baseline RULESET-0001. Source: master spec §47.

- RULE-GLOBAL-001: Agent claims are not verified facts.
- RULE-GLOBAL-002: Agents cannot declare a gate or product VERIFIED.
- RULE-GLOBAL-003: Do not silently change scope.
- RULE-GLOBAL-004: Do not overwrite verified architecture without explicit justification.
- RULE-GLOBAL-005: Do not rely on old session/chat context as project truth.
- RULE-GLOBAL-006: Read current task context and project baseline before editing.
- RULE-GLOBAL-007: If reality contradicts docs, report it.
- RULE-GLOBAL-008: Do not hide failures.
- RULE-GLOBAL-009: Do not fabricate evidence.
- RULE-GLOBAL-010: Do not perform unrelated refactors.
