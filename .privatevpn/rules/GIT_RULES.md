# GIT RULES (RULE-GIT-*)

Baseline RULESET-0001. Source: master spec §55.

- RULE-GIT-001: Inspect git status before modifications.
- RULE-GIT-002: Do not destroy uncommitted work.
- RULE-GIT-003: Use branches/worktrees for parallel conflicting writes.
- RULE-GIT-004: Never commit secrets/private keys.
- RULE-GIT-005: Commits should map logically to tasks.
- RULE-GIT-006: Handoff identifies start/end commits.
- RULE-GIT-007: Do not rewrite shared history unless authorized.
